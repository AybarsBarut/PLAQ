# Roadmap

## Research next

- Add controlled cross-axis predictors and compare exact bit costs.
- Evaluate canonical Huffman and range coding behind new, explicit codec IDs.
- Build a diverse, legally redistributable benchmark manifest with confidence
  intervals rather than one headline ratio.
- Run sustained parser/packet fuzz campaigns and publish minimized findings.

## Streaming next

- Add optional XOR parity for single-fragment recovery, then benchmark its link
  overhead; consider Reed–Solomon only behind a negotiated feature flag.
- Define retransmission and bounded playout-deadline semantics.
- Add authenticated encryption and sender identity before untrusted networks.
- Prototype USB Audio Class, Bluetooth, and Wi-Fi Direct adapters only after the
  codec-independent framing stabilizes.

## Physical model next

- Validate mass/compliance units, discretization stability, and frequency
  response against published cartridge models.
- Add optional RIAA pre/de-emphasis, wow/flutter, surface noise, and tracing
  distortion as individually switchable lossy experiments.
- Design blinded listening experiments; do not infer perceptual quality from
  compression ratio.
