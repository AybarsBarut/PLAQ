# ADR-0001: Integer trajectory coding with independent blocks

- Status: accepted for format version 1
- Date: 2026-09-03

## Context

PLAQ tests whether a reversible virtual-stylus representation exposes useful
temporal or inter-channel structure. The experiment must not confuse a physical
analogy with additional information, and every lossless claim must be directly
testable.

## Decision

Version 1 uses an integer lifting transform for stereo, four fixed integer
predictors, exhaustive per-component Rice parameter selection, block-local reset
state, CRC32C per compressed block, and SHA-256 over canonical PCM bytes. The
codec and transport framing remain separate. Floating-point stylus dynamics are
an explicit lossy command and profile-independent experiment.

## Consequences

The design is simple to inspect, fuzz, and reproduce. Exhaustive predictor
selection is intentionally CPU-heavy, the format is not competitive with mature
lossless codecs on every signal, and the current decoder buffers a bounded whole
file in memory. These are acceptable prototype tradeoffs, not hidden claims.
